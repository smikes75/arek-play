# Screenshots (from the rebuild, not from an emulator)

Game pixels, zoom 1, no CRT, no blur, device pixel ratio 1; made by `tools/present_shots.py` from the presentation page.
The PNGs are kept out of git (`.gitignore`, game graphics) and go to the website package (`build/present/shots/`).

- `original.png` and `enhanced.png` show **the same game frame** (level 1, Magic Woods, running right, paused with P): Original mode
  336 × 262 (HUD + the original 336 × 247 view) and Enhanced mode 448 × 294 (the wider 448 × 279 view drawn from the level map around the
  original window, without in-between positions). The 320 × 200 play area at the centre is identical in both (0 pixels differ); only the HUD
  is laid out wider.
- `about.png`: the About screen shown at the end of level 1.
