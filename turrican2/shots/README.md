# Screenshots

Taken from the rebuild itself (not the emulator) in game pixels: zoom 1, no CRT, no blur. They
replay a recorded run of world 1-1 (`tools/present-shots.py`).

- `original.png` – Original mode: the game's own 304 × 192 window and status bar, the spread gun
  against the flyers in the sky (game tick 3000).
- `enhanced.png` – the same moment in Enhanced: the wider 448 × 256 view and the smooth status bar.
- `enhanced-islands.png` – Enhanced later in the level: the floating islands under the sky's colour
  gradient (game tick 14000).
- `about.png` – the screen shown at the exit of 1-1: about this rebuild.
