# Screenshots (Alien Breed SE92, level 1)

Taken from the rebuild in this package (not from an emulator), in game pixels: zoom 1, no CRT, no blur (`tools/presentshots.py`).

- `original.png` - Original mode, 293 × 256: the game's own window and HUD, exactly as the translated game drew it.
- `enhanced.png` - Enhanced mode, 448 × 274, same moment: the wider playfield drawn from the level map, with aliens beyond the original window on the left.
- `about.png` - the screen shown at the lift at the end of level 1: what the rebuild is, what was measured and how it was made.
