E switches. Original = the game's own 293 × 240 window and HUD, exact pixels. Enhanced = wider 448 × 256 playfield drawn from the level map, smooth motion between game frames.

Zoom = window width in multiples of the Original width (293 px), in whole display pixels. Pixel width like the width knob of a monitor: 1.00 = square pixels, 1.04 = PAL television. The knobs and RGB channels change the picture, not the game. Each mode keeps its own settings.

The game's own sound effects through a model of the Paula chip; M turns sound on and off. The Amiga has channels 0 and 3 on the left, 1 and 2 on the right: stereo width 100 % = as the Amiga, 0 % = mono. Amiga 500 output filters; the LED filter "as the game" follows the game, which switches it off. Each mode keeps its own settings.
